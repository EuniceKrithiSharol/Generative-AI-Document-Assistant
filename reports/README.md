# 🤖 Generative AI Document Assistant

An AI-powered document analysis application that summarizes text, extracts keywords, analyzes content, and answers questions based on document information.

---

## 🚀 Project Overview

Generative AI and Natural Language Processing are transforming how users interact with information.

This project demonstrates an AI-powered document assistant capable of analyzing text and helping users quickly understand document content.

---

## ✨ Features

- Document summarization
- Keyword extraction
- Important topic identification
- Question answering
- Document analysis
- Text processing
- AI-style responses
- Interactive Streamlit dashboard

---

## 🧠 AI Techniques

### TF-IDF

Used to identify important words and sentences.

### Cosine Similarity

Used to identify document sentences most relevant to user questions.

### Extractive Summarization

Important sentences are selected to generate a concise document summary.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Generative-AI-Document-Assistant.git
```

Move into the project directory:

```bash
cd Generative-AI-Document-Assistant
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
streamlit run app.py
```
