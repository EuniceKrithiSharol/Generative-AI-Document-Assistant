# AI Document Analysis Models

This project uses Natural Language Processing and text similarity techniques.

## Techniques Used

### TF-IDF

TF-IDF converts text into numerical features based on the importance of words.

### Cosine Similarity

Cosine similarity compares the user's question with document sentences to identify relevant information.

### Extractive Summarization

Important sentences are selected based on their relevance to the overall document.
